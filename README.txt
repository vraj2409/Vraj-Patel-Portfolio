Portfolio - Vraj Nileshkumar Patel
Open index.html in a browser (double-click works; for best results run a local server: python -m http.server).
Edit the CONFIG block at the top of script.js to enable the contact form (EmailJS or Formspree).
Project buttons are labelled GitHub Profile because repository URLs are not supplied. Replace the GitHub links for projects in script.js (PROJECTS array) when repo URLs are ready.
To add the Python certificate: put Python_Pro_Bootcamp.pdf in Certificates/ (also remove unavailable:true from its entry in script.js; optionally add Certificates/previews/Python_Pro_Bootcamp.jpg).

Resume buttons open Patel Vraj N.pdf in a new tab. Coding profile buttons are in the introduction.
Contact form defaults to opening an email draft, not sending automatically.
